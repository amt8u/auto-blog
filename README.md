# Auto Blog

A Hugo blog where each post is generated by Claude with web-researched citations.

- **Site generator:** [Hugo](https://gohugo.io/) + [Bear Blog theme](https://github.com/janraasch/hugo-bearblog)
- **Articles:** Markdown in `content/posts/`
- **SEO:** description, keywords, Open Graph, Twitter cards, canonical URL, JSON-LD `Article` schema, sitemap, robots.txt
- **Publishing:** two interchangeable approaches — pick whichever suits your setup (see below)

## Setup (one-time)

```bash
# Theme submodule (already done if you cloned with --recurse-submodules)
git submodule update --init --recursive

# (optional) point baseURL at your real domain in hugo.toml
```

---

## Publisher A — `publish/claude-cli/` (claude.ai subscription, no API key)

Uses the [Claude Code](https://claude.ai/code) CLI, which authenticates with your
claude.ai subscription. No Anthropic API key or extra Python packages needed.

**Requirements:** Claude Code installed and signed in (`claude --version` should work).

```bash
python3 publish/claude-cli/publish.py "Your topic here"
# or run interactively:
python3 publish/claude-cli/publish.py
```

The script:
1. Calls the `claude` CLI with `WebSearch` enabled (up to 5 searches).
2. Parses the TOML front matter + Markdown body from the response.
3. Writes `content/posts/<YYYY-MM-DD>-<slug>.md`.
4. `git commit` + `git push` (Netlify deploys automatically on push).

---

## Publisher B — `publish/api-key/` (Anthropic API key, Flask web UI)

A local Flask page at `http://localhost:5000` that streams live progress as Claude
researches and writes. Requires an Anthropic API key from
[console.anthropic.com](https://console.anthropic.com).

**Setup (one-time):**

```bash
cd publish/api-key
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env    # edit .env and paste your ANTHROPIC_API_KEY
cd ../..
```

**Daily use:**

```bash
# Terminal 1 — live preview (optional)
hugo server -D

# Terminal 2 — the publisher UI
source publish/api-key/.venv/bin/activate
python publish/api-key/publish.py
```

Open <http://localhost:5000>, paste a topic, click **Research & Publish**. The publisher:
1. Calls `claude-sonnet-4-6` with the `web_search_20250305` tool (up to 5 searches).
2. Parses the TOML front matter + Markdown body from the response.
3. Writes `content/posts/<YYYY-MM-DD>-<slug>.md`.
4. `git commit` + `git push` (Netlify deploys automatically on push).

## Production build

```bash
hugo --gc --minify
# output is in ./public — Netlify runs this automatically on push
```

## SEO checklist (built in)

- `<title>`, `<meta name=description>`, `<meta name=keywords>` — Bear Blog `seo_tags.html`
- Open Graph + Twitter cards — Hugo internal templates
- `<link rel="canonical">` and JSON-LD `Article` schema — `layouts/partials/custom_head.html`
- `sitemap.xml` — generated by Hugo
- `robots.txt` — `static/robots.txt`

## File layout

```
hugo.toml                          # site config
content/_index.md                  # home page
content/posts/                     # generated articles land here
layouts/partials/custom_head.html  # canonical + JSON-LD
static/robots.txt
themes/hugo-bearblog/              # submodule
publish/
  claude-cli/                      # Publisher A: CLI, claude.ai subscription
    publish.py
    prompts.py
    requirements.txt               # (empty — stdlib only)
  api-key/                         # Publisher B: Flask UI, Anthropic API key
    publish.py
    prompts.py
    requirements.txt               # anthropic, flask, python-dotenv
    .env.example
```
