# Auto Blog

A Hugo blog where each post is generated by Claude with web-researched citations.

- **Site generator:** [Hugo](https://gohugo.io/) + [Bear Blog theme](https://github.com/janraasch/hugo-bearblog)
- **Articles:** Markdown in `content/posts/`
- **SEO:** description, keywords, Open Graph, Twitter cards, canonical URL, JSON-LD `Article` schema, sitemap, robots.txt
- **Publishing UI:** a local-only Flask page (`publish/publish.py`) that calls the Claude API with the `web_search` tool, parses the result into front matter + body, writes it under `content/posts/`, and commits + pushes the repo.

## Setup (one-time)

```bash
# 1. Theme submodule (already added if you cloned with --recurse-submodules)
git submodule update --init --recursive

# 2. Python env for the publisher
cd publish
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env       # then edit .env and paste your ANTHROPIC_API_KEY
cd ..

# 3. (optional) point baseURL at your real domain in hugo.toml
# 4. (optional) git remote add origin git@github.com:<you>/<repo>.git && git push -u origin main
```

## Daily flow

```bash
# Terminal 1 — live preview
hugo server -D

# Terminal 2 — the input page
source publish/.venv/bin/activate
python publish/publish.py
```

Open <http://localhost:5000>, paste a topic, click **Research & Publish**. The publisher:
1. Calls `claude-sonnet-4-6` with the `web_search_20250305` tool (up to 5 searches).
2. Parses the TOML front matter + Markdown body from the response.
3. Writes `content/posts/<YYYY-MM-DD>-<slug>.md`.
4. `git add` + `git commit -m "post: <title>"` + `git push`.

If `hugo server` is running, the post is live at <http://localhost:1313/posts/{slug}/> within seconds.

## Production build

```bash
hugo --gc --minify
# output is in ./public  — deploy that directory to Netlify / Vercel / GitHub Pages / S3 / …
```

## SEO checklist (built in)

- `<title>`, `<meta name=description>`, `<meta name=keywords>` — Bear Blog `seo_tags.html`
- Open Graph + Twitter cards — Hugo internal templates
- `<link rel="canonical">` and JSON-LD `Article` schema — `layouts/partials/custom_head.html`
- `sitemap.xml` — generated by Hugo
- `robots.txt` — `static/robots.txt`

## File layout

```
hugo.toml                       # site config
content/_index.md               # home page
content/posts/                  # generated articles land here
layouts/partials/custom_head.html  # canonical + JSON-LD
static/robots.txt
themes/hugo-bearblog/           # submodule
publish/
  publish.py                    # Flask app: form, Claude call, git push
  prompts.py                    # system + user prompts
  requirements.txt
  .env.example
```
