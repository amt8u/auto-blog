# Auto Blog

A Hugo blog (cloudmato.com) where each post is generated by Claude with web-researched citations,
and can be machine-translated into Hindi and Marathi.

- **Site generator:** [Hugo](https://gohugo.io/) + [hugo-theme-monochrome](https://github.com/kimcc/hugo-theme-monochrome)
- **Languages:** English (`en`, default), Hindi (`hi`), Marathi (`mr`) — UI strings in `i18n/`, per-language menus in `config/_default/menus/`
- **Articles:** Markdown in `content/posts/`, optionally with `.hi.md` / `.mr.md` translations alongside the English original
- **SEO:** description, keywords, Open Graph, Twitter cards, canonical URL, JSON-LD `Article` schema, sitemap, robots.txt, AdSense (`static/ads.txt`)
- **Publishing:** two interchangeable approaches for new posts — pick whichever suits your setup (see below)
- **Translation:** a standalone script turns any English post into Hindi/Marathi (see below)

## Setup (one-time)

```bash
# Theme submodule (already done if you cloned with --recurse-submodules)
git submodule update --init --recursive

# (optional) point baseURL at your real domain in hugo.toml
```

---

## Publisher A — `publish/claude-cli/` (claude.ai subscription, no API key)

Uses the [Claude Code](https://claude.ai/code) CLI, which authenticates with your
claude.ai subscription. No Anthropic API key or extra Python packages needed.

**Requirements:** Claude Code installed and signed in (`claude --version` should work).

```bash
python3 publish/claude-cli/publish.py "Your topic here"
# or run interactively:
python3 publish/claude-cli/publish.py
```

The script:
1. Calls the `claude` CLI with `WebSearch` enabled (up to 5 searches).
2. Parses the TOML front matter + Markdown body from the response.
3. Extracts any inline `<!-- SVG_FILE -->` blocks into `static/images/posts/<slug>/` for the feature image.
4. Writes `content/posts/<YYYY-MM-DD>-<slug>.md`.
5. `git commit` + `git push` (Netlify deploys automatically on push).

Run `translate.py` afterwards to add Hindi/Marathi versions of the new post (see below).

---

## Publisher B — `publish/api-key/` (Anthropic API key, Flask web UI)

A local Flask page at `http://localhost:5000` that streams live progress as Claude
researches and writes. Requires an Anthropic API key from
[console.anthropic.com](https://console.anthropic.com).

**Setup (one-time):**

```bash
cd publish/api-key
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env    # edit .env and paste your ANTHROPIC_API_KEY
cd ../..
```

**Daily use:**

```bash
# Terminal 1 — live preview (optional)
hugo server -D

# Terminal 2 — the publisher UI
source publish/api-key/.venv/bin/activate
python publish/api-key/publish.py
```

Open <http://localhost:5000>, paste a topic, click **Research & Publish**. The publisher:
1. Calls `claude-sonnet-4-6` with the `web_search_20250305` tool (up to 5 searches).
2. Parses the TOML front matter + Markdown body from the response.
3. Generates/extracts an SVG feature image for the post.
4. Writes `content/posts/<YYYY-MM-DD>-<slug>.md`.
5. `git commit` + `git push` (Netlify deploys automatically on push).

## Translation — `publish/claude-cli/translate.py` (Hindi / Marathi)

Takes an existing English post and produces a translated copy alongside it, e.g.
`2026-06-14-POST-1059-how-openai-anthropic-train-models.hi.md`. Uses the same `claude` CLI
as Publisher A — no API key needed.

```bash
python3 publish/claude-cli/translate.py            # prompts for post number + language
python3 publish/claude-cli/translate.py 1059       # prompts for language only
python3 publish/claude-cli/translate.py 1059 hindi # fully non-interactive
```

The script:
1. Finds the English post matching `POST-<number>` in `content/posts/`.
2. Sends it to `claude` with language-specific rules (Hindi keeps front matter mostly translated;
   Marathi keeps `tags` in English), preserving slug, dates, images, and Markdown formatting.
3. Writes `<same-name>.<hi|mr>.md` with `canonical` updated to `/hi/posts/<slug>/` or `/mr/posts/<slug>/`.
4. `git commit` + `git push`.

If the translation comes back malformed, nothing is committed and the raw output is saved to
`publish/.last-translate-<lang>-<slug>.md` for inspection.

Supported languages today: **Hindi** (`hi`) and **Marathi** (`mr`) — see the `LANGUAGES` dict in
`translate.py` to add more.

## SEO checklist (built in)

- `<title>`, `<meta name=description>`, `<meta name=keywords>` — theme SEO templates
- Open Graph + Twitter cards — Hugo internal templates
- `<link rel="canonical">` and JSON-LD `Article` schema — theme templates + front matter
- AdSense — `static/ads.txt` + `<meta name="google-adsense-account">` in `layouts/_partials/user_head.html`
- `sitemap.xml` — generated by Hugo
- `robots.txt` — `static/robots.txt`

## File layout

```
hugo.toml                          # site config (en/hi/mr languages, theme, params)
content/_index.md, _index.hi.md, _index.mr.md  # home page per language
content/posts/                     # generated articles + .hi.md/.mr.md translations
content/pages/                     # about, contact, privacy, terms (+ hi/mr)
i18n/                              # UI string translations (en/hi/mr)
config/_default/menus/             # per-language navbar menus
layouts/_partials/user_head.html   # extra <head> tags (AdSense, fonts, canonical, JSON-LD)
static/ads.txt
static/robots.txt
static/images/posts/<slug>/        # generated SVG feature images
themes/hugo-theme-monochrome/      # submodule
publish/
  writing-style.md                 # style guide injected into the generation prompt
  claude-cli/                      # Publisher A: CLI, claude.ai subscription
    publish.py
    prompts.py
    translate.py                   # Hindi/Marathi translation script
    requirements.txt               # (empty — stdlib only)
  api-key/                         # Publisher B: Flask UI, Anthropic API key
    publish.py
    prompts.py
    requirements.txt               # anthropic, flask, python-dotenv
    .env.example
```
