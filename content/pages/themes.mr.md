## Hugo थीम्स — काय पहावे

Hugo मध्ये शेकडो थीम्स आहेत. बहुतेक स्क्रीनशॉटमध्ये ठीक दिसतात आणि तुम्ही त्या कस्टमाइझ करण्याचा प्रयत्न करताच कोसळतात. हे पृष्ठ थीम निवडताना खरोखर काय महत्त्वाचे आहे ते कव्हर करते आणि या साइटला चालवणारी थीम हायलाइट करते.

---

## एक चांगली Hugo थीम काय बनवते

### परफॉर्मन्स प्रथम

ब्लॉग रेंडर करण्यासाठी 400KB JavaScript लोड करणारी थीम थीम नाही — ती एक समस्या आहे. चांगल्या Hugo थीम्स किमान CSS, शून्य किंवा जवळजवळ-शून्य JavaScript पाठवतात आणि Hugo च्या ऍसेट पाइपलाइनला जड काम करू देतात.

**लाल झेंडे:** बंडल केलेले jQuery, SVG ऐवजी आयकॉन फॉन्ट्स, थीममध्ये बेक केलेल्या ऑप्टिमाइझ न केलेल्या प्रतिमा, कोणतेही ऍसेट फिंगरप्रिंटिंग नाही.

### बहुभाषिक समर्थन

जर तुमचे प्रेक्षक एकापेक्षा जास्त भाषा बोलत असतील, तर बहुभाषिक समर्थन बोलण्यायोग्य नाही. याचा अर्थ प्रत्येक भाषेसाठी i18n अनुवाद फाइल्स, प्रति-भाषा मेनू कॉन्फिगरेशन, आणि वेगळ्या स्लगसह प्रत्येक भाषेसाठी डुप्लिकेट केलेले कंटेंट.

Hugo चा बिल्ट-इन i18n सिस्टम उत्कृष्ट आहे — परंतु थीम त्यासाठी तयार असणे आवश्यक आहे. अनेक थीम्स बहुभाषिक समर्थनाचा दावा करतात आणि केवळ भाषा स्विचर देतात.

### स्वच्छ मार्कअप

सेमँटिक HTML तयार करणाऱ्या थीम्स — योग्य हेडिंग श्रेणीबद्धता, `<article>`, `<nav>`, `<main>`, `<time>` — स्टाइल, इंडेक्स आणि प्रवेशयोग्य बनवणे खूप सोपे आहे. सर्वासाठी `<div>` वापरणाऱ्या थीम्स प्रत्येक पावलावर तुमच्याशी भांडतील.

### सक्रिय देखभाल

थीमचे GitHub रिपॉझिटरी तपासा. शेवटचे कमिट कधी होते? समस्यांना उत्तर दिले जात आहे का? दोन वर्षांत स्पर्श न झालेली थीम Hugo अपग्रेड होताच डेप्रिकेशन चेतावण्या देऊ लागेल.

### ओव्हरराइड-अनुकूल लेआउट

Hugo च्या टेम्पलेट लुकअप ऑर्डरचा अर्थ आहे की तुम्ही प्रोजेक्टच्या `layouts/` डिरेक्टरीखाली समान फाइल तयार करून कोणतेही थीम पार्शल ओव्हरराइड करू शकता. चांगल्या थीम्स अशा रचल्या जातात की ओव्हरराइड शस्त्रक्रियापूर्वक असतात — हेडरसाठी एक पार्शल, फुटरसाठी एक, प्रत्येक कंटेंट प्रकारासाठी एक. वाईट थीम्स सर्वकाही एका फाइलमध्ये टाकतात.

## या साइटला चालवणारी थीम

ही साइट kaiiiz ची **[hugo-theme-monochrome](https://github.com/kaiiiz/hugo-theme-monochrome)** वापरते.

### मोनोक्रोम का?

| वैशिष्ट्य | स्थिती |
|---|---|
| बहुभाषिक / i18n | ✅ हिंदी आणि मराठीसह 56 भाषा |
| डार्क / लाइट मोड | ✅ ऑटो-डिटेक्ट + मॅन्युअल टॉगल |
| विषय-सूची | ✅ उजव्या बाजूचे फिक्स्ड पॅनेल |
| साइट शोध | ✅ बिल्ट-इन, कोणती बाह्य सेवा नाही |
| सिंटॅक्स हायलाइटिंग | ✅ कॉपी बटणासह Prism.js |
| Math समर्थन | ✅ MathJax पर्यायी |
| परफॉर्मन्स | ✅ किमान JS, SCSS पाइपलाइन |
| Hugo आवृत्ती आवश्यक | `>= 0.146.0` (extended) |

### या साइटवर कस्टमायझेशन

- पोस्ट कार्डमध्ये फीचर इमेज (इमेज डावीकडे, कंटेंट उजवीकडे)
- फीचर इमेजशिवाय पोस्टसाठी डिफॉल्ट फॉलबॅक इमेज
- हिंदी आणि मराठी i18n अनुवाद फाइल्स जोडल्या
- थीमच्या बिल्ट-इन हुकद्वारे कस्टम `user.css` इंजेक्ट केले

## इतर उल्लेखनीय थीम्स

### [PaperMod](https://github.com/adityatelange/hugo-PaperMod)

GitHub वर सर्वात लोकप्रिय Hugo थीम. वेगवान, स्वच्छ, चांगले राखलेले आणि खरोखर बहुभाषिक. ब्लॉग किंवा पोर्टफोलिओसाठी चांगली डिफॉल्ट निवड.

### [Blowfish](https://github.com/nunocoracao/blowfish)

आधुनिक, फीचर-रिच, Tailwind सह तयार. उत्कृष्ट दस्तऐवजीकरण. वैयक्तिक साइट आणि डेव्हलपर पोर्टफोलिओसाठी चांगले.

### [Congo](https://github.com/jpanther/congo)

Hugo मॉड्यूल-आधारित, Tailwind-चालित, मजबूत i18n समर्थन. खूप सक्रियपणे राखले जाते.

### [Hextra](https://github.com/imfing/hextra)

दस्तऐवजीकरण-केंद्रित थीम. स्वच्छ, वेगवान, चांगला शोध. जर तुम्हाला ब्लॉगऐवजी डॉक्स साइट हवी असेल तर पाहण्यासारखे.

## तुमची स्वतःची थीम तयार करणे

Hugo थीम्स फक्त Go टेम्पलेट्स, SCSS आणि स्टॅटिक ऍसेट्स आहेत. जर कोणतीही उपलब्ध थीम अगदी बसत नसेल, तर हे पूर्णपणे व्यावहारिक आहे:

1. विद्यमान थीम फोर्क करा आणि ती बदला
2. बेअर `baseof.html` पासून सुरू करा आणि वर तयार करा
3. Hugo मॉड्यूलद्वारे थीम अवलंबित्व म्हणून वापरा आणि फक्त आवश्यक पार्शल्स ओव्हरराइड करा

तिसरा दृष्टिकोन हाच ही साइट करते — monochrome एक git submodule आहे, आणि फक्त ज्या पार्शल्समध्ये बदल करणे आवश्यक होते त्या प्रोजेक्टच्या `layouts/` डिरेक्टरीमध्ये ओव्हरराइड आहेत.
