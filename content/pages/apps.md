## Auto Blog

**A fully automated Hugo blog engine powered by Claude AI.**

The site you are reading right now is built on Auto Blog — an open publishing pipeline that takes a topic, researches it using live web search, writes a cited article, translates it to Hindi, and pushes it to Netlify. No CMS, no dashboard, no manual drafting.

**Stack:** Hugo · Claude API · Python · Netlify · GitHub Actions

**What it does:**
- Research-backed article generation with inline citations
- Automatic Hindi translation for every post
- SVG diagram generation embedded directly in articles
- Feature image discovery from Unsplash
- One-command publish from terminal
